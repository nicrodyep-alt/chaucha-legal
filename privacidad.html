Política de privacidad de Chaucha

Última actualización: 26 de octubre de 2026

Chaucha es una aplicación personal de uso privado. Esta política explica qué datos usa y cómo los trata. Quien usa la aplicación es el mismo titular de la cuenta de Google que la autoriza: su desarrollador.

Qué datos se acceden

Con el permiso de lectura de Gmail que el titular otorga, la aplicación consulta únicamente los correos de aviso que envían las entidades financieras del titular (consumos con tarjeta y transferencias). No lee, guarda ni usa otros correos.

Qué se guarda

De cada aviso se guardan solo los datos necesarios para registrar el gasto: comercio o beneficiario, monto, fecha, tipo de movimiento y el identificador del correo para no duplicar registros. Los números de cuenta o de tarjeta se enmascaran y solo se conservan sus últimos cuatro dígitos.

Dónde se guardan

Los registros se almacenan en una base de datos privada del titular, protegida por inicio de sesión y reglas de acceso, de modo que solo él puede verlos. Las copias de respaldo, cuando existen, se guardan cifradas y también son privadas.

Con quién se comparten

No se venden, ceden ni comparten datos con terceros ni se usan para publicidad. Como apoyo opcional para sugerir la categoría de un gasto dudoso, la aplicación podría enviar a un servicio de inteligencia artificial únicamente el nombre del comercio, el monto y la fecha, sin números de cuenta ni contenido del correo, y la sugerencia nunca se aplica sin confirmación del titular.

Uso de la información de Google

El uso y la transferencia de la información recibida de las API de Google se ajustan a la Política de datos de usuario de los Servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo retirar el acceso o borrar los datos

El titular puede revocar el acceso en cualquier momento desde la configuración de su cuenta de Google (Seguridad, Conexiones de terceros) y borrar sus registros de la base de datos.
